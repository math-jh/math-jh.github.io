정수는 덧셈·뺄셈·곱셈에 대해 닫혀 있지만 나눗셈에 대해서는 닫혀 있지 않다. $6$을 $2$로 나눈 결과는 정수이지만 $7$을 $2$로 나눈 결과는 정수가 아니다. 정수론은 이 차이에서 출발한다. 이 글에서는 나누어떨어짐을 정의하고, 나누어떨어지지 않는 경우에도 언제나 가능한 나머지 있는 나눗셈을 증명한 다음, 이를 반복하여 최대공약수를 계산하는 유클리드 호제법과 그 부산물인 Bézout 항등식, 그리고 일차 부정방정식의 풀이까지 다룬다. 음이 아닌 정수로 이루어진 공집합이 아닌 집합은 항상 가장 작은 원소를 갖는다는 정렬성(well-ordering)은 이미 알려진 사실로 사용한다.

## 나누어떨어짐

::: 정의 1
정수 $a, b$에 대하여 $b = ac$인 정수 $c$가 존재할 때 *$a$가 $b$를 나눈다<sub>$a$ divides $b$</sub>*고 하고 $a \mid b$로 적는다. 이때 $a$를 $b$의 *약수<sub>divisor</sub>*, $b$를 $a$의 *배수<sub>multiple</sub>*라 한다. 나누지 않을 때는 $a \nmid b$로 적는다.
:::

정의는 나눗셈 $b/a$가 아니라 곱셈 $b = ac$로 서술되어 있으므로 $0$이 관여하는 경우도 그대로 처리된다. 모든 정수 $a$에 대하여 $a \mid 0$이고($0 = a \cdot 0$), $0 \mid b$는 $b = 0$일 때에만 성립한다. 또한 $a \mid b$는 $\pm a$, $\pm b$의 부호 조합에 영향을 받지 않으므로 약수는 보통 양의 약수만 따진다.

::: 명제 2
정수 $a, b, c$에 대하여 다음이 성립한다.

1. $a \mid b$이고 $b \mid c$이면 $a \mid c$이다.
2. $a \mid b$이고 $a \mid c$이면 임의의 정수 $x, y$에 대하여 $a \mid bx + cy$이다.
3. $a \mid b$이고 $b \neq 0$이면 $\lvert a\rvert \leq \lvert b\rvert$이다.
:::

::: 증명
(1) $b = ad$, $c = be$인 정수 $d, e$가 있으므로 $c = a(de)$이다.

(2) $b = ad$, $c = ae$이면 $bx + cy = a(dx + ey)$이다.

(3) $b = ac$에서 $b \neq 0$이므로 $c \neq 0$이고, 따라서 $\lvert c\rvert \geq 1$이다. 그러므로 $\lvert b\rvert = \lvert a\rvert\lvert c\rvert \geq \lvert a\rvert$이다.
:::

(2)는 이 글 전체에서 가장 자주 쓰이는 형태로, $a$의 배수들의 정수계수 일차결합은 다시 $a$의 배수라는 뜻이다. (3)에 의하여 $0$이 아닌 정수의 약수는 유한 개이다.

## 나눗셈 정리

::: 정리 3 (나눗셈 정리)
정수 $a$와 양의 정수 $b$에 대하여 다음을 만족하는 정수 $q, r$이 유일하게 존재한다.

$$a = bq + r, \qquad 0 \leq r < b$$

$q$를 *몫<sub>quotient</sub>*, $r$을 *나머지<sub>remainder</sub>*라 한다.
:::

::: 증명
존재성. $S = \{a - bk \mid k \in \mathbb{Z},\ a - bk \geq 0\}$으로 두자. $k = -\lvert a\rvert$이면 $b \geq 1$이므로 $a - bk = a + b\lvert a\rvert \geq a + \lvert a\rvert \geq 0$이고, 따라서 $S$는 공집합이 아닌 음이 아닌 정수의 집합이다. 정렬성에 의하여 $S$는 가장 작은 원소 $r = a - bq$를 갖는다. $r \geq 0$은 $S$의 정의에서 나온다. $r \geq b$라 가정하면 $r - b = a - b(q+1) \geq 0$이므로 $r - b \in S$인데 $r - b < r$이어서 $r$의 최소성에 모순이다. 따라서 $r < b$이다.

유일성. $a = bq + r = bq' + r'$이고 $0 \leq r, r' < b$라 하자. 그러면 $b(q - q') = r' - r$이므로 $b \mid r' - r$이다. 한편 $-b < r' - r < b$에서 $\lvert r' - r\rvert < b$이다. $r' - r \neq 0$이면 [명제 2](#prop2)의 (3)에 의하여 $\lvert r' - r\rvert \geq b$이므로 모순이고, 따라서 $r = r'$이다. 그러면 $b(q - q') = 0$이고 $b > 0$이므로 $q = q'$이다.
:::

$b$가 음의 정수인 경우에는 $\lvert b\rvert$에 [정리 3](#thm3)을 적용하여 $a = \lvert b\rvert q' + r$을 얻고 $q = \pm q'$로 두면 $a = bq + r$, $0 \leq r < \lvert b\rvert$이 된다. 나머지는 항상 $0$ 이상이라는 점에서 음수의 나눗셈에 주의가 필요하다. 가령 $-47$을 $8$로 나누면 $-47 = 8 \cdot (-6) + 1$이므로 $q = -6$, $r = 1$이고, $-47 = 8 \cdot (-5) + (-7)$은 $r < 0$이므로 나눗셈 정리의 표현이 아니다. 또 $r = 0$인 것은 $b \mid a$인 것과 동치이다.

## 최대공약수

::: 정의 4
둘 다 $0$은 아닌 정수 $a, b$에 대하여, $a$와 $b$의 공약수 중 가장 큰 정수를 *최대공약수<sub>greatest common divisor</sub>*라 하고 $\gcd(a, b)$로 적는다. $\gcd(a, b) = 1$일 때 $a, b$는 *서로소*라 한다.
:::

$1$은 항상 공약수이고, [명제 2](#prop2)의 (3)에 의하여 공약수는 $\max(\lvert a\rvert, \lvert b\rvert)$를 넘지 못하므로 최대공약수는 잘 정의된다. 정의에서 곧바로 $\gcd(a, b) = \gcd(b, a) = \gcd(\lvert a\rvert, \lvert b\rvert)$이고, $a \neq 0$이면 $\gcd(a, 0) = \lvert a\rvert$이며, $b \mid a$이면 $\gcd(a, b) = \lvert b\rvert$이다. 따라서 이하에서는 필요하면 $a, b$를 양의 정수로 바꾸어 생각한다. $\gcd(12, 18) = 6$처럼 작은 수는 약수를 나열하여 구할 수 있지만, 수가 커지면 이는 사실상 소인수분해를 요구하여 현실적이지 않다. 다음 보조정리가 그 대안의 출발점이다.

::: 보조정리 5
정수 $a, b$와 $a = bq + r$인 정수 $q, r$에 대하여 $b \neq 0$이면 $\gcd(a, b) = \gcd(b, r)$이다.
:::

::: 증명
$a, b$의 공약수 전체의 집합과 $b, r$의 공약수 전체의 집합이 같음을 보이면 충분하다. $d \mid a$, $d \mid b$이면 $r = a \cdot 1 + b \cdot (-q)$이므로 [명제 2](#prop2)의 (2)에 의하여 $d \mid r$이다. 역으로 $d \mid b$, $d \mid r$이면 $a = b \cdot q + r \cdot 1$이므로 $d \mid a$이다. 두 집합이 같으므로 그 최댓값도 같다. $b \neq 0$이므로 두 쌍 모두 둘 다 $0$인 경우가 아니다.
:::

여기서 $q$는 나눗셈 정리의 몫일 필요가 없고 임의의 정수여도 된다.

## 유클리드 호제법

$a \geq b > 0$인 정수에서 시작하여 [정리 3](#thm3)을 반복 적용한다. $r_0 = a$, $r_1 = b$로 두고, $r_i \neq 0$인 동안

$$r_{i-1} = q_i r_i + r_{i+1}, \qquad 0 \leq r_{i+1} < r_i$$

로 $q_i, r_{i+1}$을 정한다. 나머지열은 $b = r_1 > r_2 > \cdots \geq 0$으로 엄밀히 감소하는 음이 아닌 정수열이므로 유한 번 만에 $0$이 되고, $r_{k+1} = 0$이 되는 첫 $k$를 잡는다. 이 절차가 *유클리드 호제법<sub>Euclidean algorithm</sub>*이다.

::: 정리 6 (유클리드 호제법의 정당성)
위의 절차에서 $\gcd(a, b) = r_k$, 즉 $0$이 아닌 마지막 나머지가 최대공약수이다.
:::

::: 증명
$i = 1, \ldots, k$에 대하여 $r_i \neq 0$이므로 [보조정리 5](#lem5)를 적용할 수 있고

$$\gcd(a, b) = \gcd(r_0, r_1) = \gcd(r_1, r_2) = \cdots = \gcd(r_k, r_{k+1}) = \gcd(r_k, 0) = r_k$$

이다.
:::

::: 예시 7 ($\gcd(1071, 462)$)
나눗셈을 반복하면

$$\begin{aligned}
1071 &= 2 \cdot 462 + 147, \\
462 &= 3 \cdot 147 + 21, \\
147 &= 7 \cdot 21 + 0
\end{aligned}$$

이므로 $\gcd(1071, 462) = 21$이다. 약수를 나열하지 않고 세 번의 나눗셈으로 얻은 결과이다.
:::

## Bézout 항등식

::: 정리 8 (Bézout 항등식)
둘 다 $0$은 아닌 정수 $a, b$에 대하여, 집합 $S = \{ax + by \mid x, y \in \mathbb{Z}\}$의 가장 작은 양의 원소가 $\gcd(a, b)$이다. 특히 $\gcd(a, b) = ax + by$인 정수 $x, y$가 존재한다. 또한 $S$는 $\gcd(a, b)$의 배수 전체와 같다.
:::

::: 증명
$S$의 양의 원소 집합은 공집합이 아니다. $a \neq 0$이면 $a \cdot (\pm 1) + b \cdot 0 = \lvert a\rvert$이 원소이고, $a = 0$이면 $b \neq 0$이므로 $\lvert b\rvert$이 원소이다. 정렬성에 의하여 가장 작은 양의 원소 $d = ax_0 + by_0$이 존재한다.

먼저 $d$가 $a$를 나눔을 보인다. [정리 3](#thm3)으로 $a = dq + r$, $0 \leq r < d$라 하면

$$r = a - dq = a(1 - qx_0) + b(-qy_0) \in S$$

이다. $r > 0$이면 $d$보다 작은 $S$의 양의 원소가 되어 $d$의 최소성에 모순이므로 $r = 0$이고 $d \mid a$이다. 같은 논증으로 $d \mid b$이다. 따라서 $d$는 공약수이다. 한편 $c$가 임의의 공약수이면 [명제 2](#prop2)의 (2)에 의하여 $c \mid ax_0 + by_0 = d$이므로 $c \leq d$이다. 그러므로 $d = \gcd(a, b)$이다.

마지막 주장을 보이자. $d \mid a$, $d \mid b$이므로 [명제 2](#prop2)의 (2)에 의하여 $S$의 모든 원소는 $d$의 배수이다. 역으로 임의의 정수 $k$에 대하여 $kd = a(kx_0) + b(ky_0) \in S$이다.
:::

증명 중에 얻어진 사실을 따로 적어 둔다. 공약수 $c$가 $c \mid d$를 만족한다는 것은, 최대공약수가 크기뿐 아니라 나누어떨어짐 관계에서도 모든 공약수 위에 놓인다는 뜻이다.

::: 따름정리 9
둘 다 $0$은 아닌 정수 $a, b$의 모든 공약수는 $\gcd(a, b)$를 나눈다. 또한 $a, b$가 서로소인 것은 $ax + by = 1$인 정수 $x, y$가 존재하는 것과 동치이다. $d = \gcd(a, b)$이면 $a/d$와 $b/d$는 서로소이다.
:::

::: 증명
첫째 주장은 위 증명에서 $c \mid d$를 보인 부분이다. 둘째 주장에서 $\Rightarrow$는 [정리 8](#thm8)이고, $\Leftarrow$는 $ax + by = 1$이면 $a, b$의 공약수가 $1$을 나누므로 공약수가 $\pm 1$뿐인 데서 나온다. 셋째 주장은 $ax_0 + by_0 = d$의 양변을 $d$로 나눈 $(a/d)x_0 + (b/d)y_0 = 1$에서 둘째 주장으로 얻어진다.
:::

Bézout 항등식은 존재만 말하며 계수 $x, y$는 유일하지 않다. 예를 들어 $21 = 1071 \cdot (-3) + 462 \cdot 7$이지만 $21 = 1071 \cdot 19 + 462 \cdot (-44)$이기도 하다 ($20349 - 20328 = 21$). 계수의 비유일성은 아래 일반해의 구조로 정확히 설명된다.

## 확장 유클리드 알고리즘

계수 $x, y$를 실제로 구하려면 호제법을 진행하면서 각 나머지를 $a, b$의 일차결합으로 함께 기록한다. $r_i = a s_i + b t_i$를 만족하는 정수 $s_i, t_i$를 $(s_0, t_0) = (1, 0)$, $(s_1, t_1) = (0, 1)$에서 시작하여

$$s_{i+1} = s_{i-1} - q_i s_i, \qquad t_{i+1} = t_{i-1} - q_i t_i$$

로 정한다. 그러면 $i = 0, 1$에서는 $r_0 = a$, $r_1 = b$가 성립하고, $r_{i-1} = a s_{i-1} + b t_{i-1}$과 $r_i = a s_i + b t_i$를 가정하면

$$r_{i+1} = r_{i-1} - q_i r_i = a(s_{i-1} - q_i s_i) + b(t_{i-1} - q_i t_i)$$

이므로 귀납법에 의하여 모든 $i$에 대하여 $r_i = a s_i + b t_i$이다. 특히 $\gcd(a, b) = r_k = a s_k + b t_k$이다. 호제법의 등식을 마지막에서 처음으로 거슬러 올라가며 대입하는 역대입은 이 계산을 거꾸로 수행하는 것과 같다.

::: 예시 10 ($1071x + 462y = 21$)
[예시 7](#ex7)의 몫은 $q_1 = 2$, $q_2 = 3$, $q_3 = 7$이다. 점화식을 적용하면

$$\begin{aligned}
(s_2, t_2) &= (1, 0) - 2(0, 1) = (1, -2), \\
(s_3, t_3) &= (0, 1) - 3(1, -2) = (-3, 7), \\
(s_4, t_4) &= (1, -2) - 7(-3, 7) = (22, -51)
\end{aligned}$$

이다. $r_3 = 21$이 최대공약수이므로 $(x, y) = (s_3, t_3) = (-3, 7)$이고, 실제로 $-3213 + 3234 = 21$이다. $r_4 = 0$에 대응하는 $(s_4, t_4) = (22, -51)$은 $1071 \cdot 22 + 462 \cdot (-51) = 0$을 만족한다. 이 쌍이 $(b/d, -a/d) = (22, -51)$ 꼴이라는 점은 아래 [정리 14](#thm14)에서 일반해의 주기로 나타난다.
:::

법 $m$에 대한 곱셈 역원도 같은 방법으로 얻는다. $\gcd(a, m) = 1$이면 $ax + my = 1$의 해 $x$가 $ax \equiv 1 \pmod{m}$을 만족한다.

## 최소공배수

::: 명제 11
정수 $a, b, c$에 대하여 $a \mid bc$이고 $\gcd(a, b) = 1$이면 $a \mid c$이다.
:::

::: 증명
[따름정리 9](#cor9)에 의하여 $ax + by = 1$인 정수 $x, y$가 있다. 양변에 $c$를 곱하면 $c = a(cx) + (bc)y$이다. 우변의 두 항이 모두 $a$의 배수이므로 [명제 2](#prop2)의 (2)에 의하여 $a \mid c$이다.
:::

서로소 조건은 빠질 수 없다. $6 \mid 4 \cdot 9 = 36$이지만 $\gcd(6, 4) = 2$이고 $6 \nmid 4$, $6 \nmid 9$이다.

::: 정의 12
$0$이 아닌 정수 $a, b$에 대하여 $a, b$의 양의 공배수 중 가장 작은 것을 *최소공배수<sub>least common multiple</sub>*라 하고 $\lcm(a, b)$로 적는다.
:::

$\lvert ab\rvert$이 양의 공배수이므로 정렬성에 의하여 최소공배수는 잘 정의된다.

::: 명제 13
양의 정수 $a, b$에 대하여 $d = \gcd(a, b)$라 하면 $a, b$의 공배수는 정확히 $\lcm(a, b)$의 배수이고, 

$$\gcd(a, b) \cdot \lcm(a, b) = ab$$

이다.
:::

::: 증명
$a = da'$, $b = db'$로 쓰면 [따름정리 9](#cor9)에 의하여 $\gcd(a', b') = 1$이다. $m = da'b'$으로 두면 $m = ab' = ba'$이므로 $m$은 공배수이다. $n$이 임의의 공배수라 하자. $a \mid n$이므로 $n = ak = da'k$인 정수 $k$가 있고, $b \mid n$에서 $db' \mid da'k$, 즉 $b' \mid a'k$이다. $\gcd(a', b') = 1$이므로 [명제 11](#prop11)에 의하여 $b' \mid k$이고, 따라서 $n$은 $ab'= m$의 배수이다. 그러므로 양의 공배수 중 가장 작은 것은 $m$이고 모든 공배수는 $m$의 배수이다. 따라서 $\lcm(a, b) = m$이고

$$\gcd(a, b) \cdot \lcm(a, b) = d \cdot da'b' = (da')(db') = ab$$

이다.
:::

[예시 7](#ex7)의 결과를 쓰면 $\lcm(1071, 462) = 1071 \cdot 462/21 = 23562$이다. 음의 정수에 대해서는 $\lcm(a, b) = \lcm(\lvert a\rvert, \lvert b\rvert)$로 계산한다.

## 일차 부정방정식

::: 정리 14
$a, b$가 $0$이 아닌 정수이고 $d = \gcd(a, b)$일 때, 정수 $c$에 대하여 방정식 $ax + by = c$가 정수해를 갖는 것은 $d \mid c$인 것과 동치이다. 이때 한 해 $(x_0, y_0)$이 주어지면 일반해는

$$x = x_0 + \frac{b}{d}t, \qquad y = y_0 - \frac{a}{d}t \qquad (t \in \mathbb{Z})$$

이다.
:::

::: 증명
해가 존재하면 $d \mid a$, $d \mid b$이므로 [명제 2](#prop2)의 (2)에 의하여 $d \mid c$이다. 역으로 $c = dk$이면 [정리 8](#thm8)에서 $ax' + by' = d$인 $x', y'$가 있으므로 $(kx', ky')$이 해이다.

주어진 $t$에 대하여 위의 $(x, y)$가 해임은 대입으로 확인된다. 역으로 $(x, y)$를 임의의 해라 하자. $ax + by = ax_0 + by_0$에서 $a(x - x_0) = -b(y - y_0)$이고, 양변을 $d$로 나누면 $a'(x - x_0) = -b'(y - y_0)$ ($a' = a/d$, $b' = b/d$)이다. 이때 $b' \mid a'(x - x_0)$이고 $\gcd(a', b') = 1$이므로 [명제 11](#prop11)에 의하여 $b' \mid x - x_0$이다. $x - x_0 = b't$로 쓰면 $a'b't = -b'(y - y_0)$이고 $b' \neq 0$이므로 $y = y_0 - a't$이다.
:::

$a, b$ 중 하나가 $0$이면, 가령 $a = 0$일 때 방정식은 $by = c$이므로 $b \mid c$인 경우의 해 $y = c/b$와 임의의 $x$가 전부이다.

이 정리에서 두 가지를 읽을 수 있다. 첫째, 해가 존재하더라도 $a, b$가 서로소가 아니면 $c$의 선택이 제한된다. $1071x + 462y = 50$은 $21 \nmid 50$이므로 해가 없다. 둘째, 일반해에서 한 해를 다른 해로 옮기는 단위는 $b$와 $a$가 아니라 $b/d$와 $a/d$이다. 이 점을 놓치면 해를 잃는다.

::: 예시 15 (주기를 $b$로 쓰는 실수)
$6x + 4y = 10$에서 $d = 2$이고 $(x_0, y_0) = (1, 1)$이 한 해이다. [정리 14](#thm14)에 의하여 일반해는 $x = 1 + 2t$, $y = 1 - 3t$이다. 주기를 $b = 4$, $a = 6$으로 쓰면 $x = 1 + 4t$, $y = 1 - 6t$가 되어 $t = 1$에서 $(5, -5)$만 얻고, 정수해 $(3, -2)$ ($18 - 8 = 10$)는 빠진다. $(3, -2)$는 올바른 일반해의 $t = 1$에 해당한다.
:::

이제 [예시 10](#ex10)의 계수를 써서 $1071x + 462y = 63$을 풀자. $63 = 3 \cdot 21$이므로 $d \mid 63$이고, $(x_0, y_0) = 3 \cdot (-3, 7) = (-9, 21)$이 한 해이다 ($-9639 + 9702 = 63$). $b/d = 22$, $a/d = 51$이므로 일반해는 $x = -9 + 22t$, $y = 21 - 51t$이다. 같은 방식으로 $21 = 1071x + 462y$의 해는 $(-3 + 22t, 7 - 51t)$이고, $t = 1$일 때 앞에서 본 $(19, -44)$가 얻어진다.
