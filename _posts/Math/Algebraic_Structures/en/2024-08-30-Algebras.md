We now define the notion of an $A$-algebra. An algebra is a structure obtained by adding to an $A$-module $M$ a multiplication structure compatible with the additive structure and scalar multiplication of $M$; this is the same process as defining on an abelian group $G$ a multiplication compatible with the addition of $G$. However, there are two problems with using [§Definition of a Ring, ⁋Definition 1](/en/math/algebraic_structures/rings#def1){: data-relation="required" } directly.

First, the first problem is that for a general ring $A$, $\lMod{A}$ or $\rMod{A}$ is not a monoidal category. If $A$ is a commutative ring, then $(\lMod{A},\otimes_A, A)$ becomes a symmetric monoidal category, so this is resolved by assuming that $A$ is a commutative ring. ([§Direct Products, Direct Sums, and Tensor Products of Modules, §§Tensor Products of Modules over Commutative Rings](/en/math/algebraic_structures/operations_of_modules#tensor-products-of-modules-over-commutative-rings){: data-relation="required" })

The second problem is an issue from a historical perspective: if, as done previously, we fix a commutative ring $A$ and, in the symmetric monoidal category $(\lMod{A},\otimes_A,A)$, call a monoid object $E$ an $A$-algebra, then because of the associativity axiom and unit axiom of a monoid object, the multiplication of $E$ must always satisfy associativity and have an identity element. Yet examples that have been studied so far and play important roles often do not satisfy these properties. Therefore, to include all of them, one must abandon associativity and the existence of an identity element, which also means that one must partially abandon a definition such as [§Definition of a Ring, ⁋Definition 1](/en/math/algebraic_structures/rings#def1){: data-relation="required" }.

For these reasons, we shall henceforth assume that $A$ is always a commutative ring, and define an $A$-algebra as follows.

::: Definition 1
If an $A$-module $E$ is equipped with an $A$-bilinear map $\mu:E\times E \rightarrow E$, then $E$ is called an *$A$-algebra*. In addition, depending on the properties satisfied by $E$'s multiplication $\mu$, we define the following.

- If the multiplication of $E$ is commutative, it is called a *commutative $A$-algebra*.
- If the multiplication of $E$ is associative, it is called an *associative $A$-algebra*.
- If the multiplication of $E$ has an identity element, it is called a *unital $A$-algebra*.
:::

Then a monoid object in $(\lMod{A},\otimes_A,A)$ is an associative unital $A$-algebra.

Meanwhile, an associative unital $A$-algebra can be thought of as an $A$-module $E$ equipped with a multiplication, but also as a ring $E$ equipped with a scalar multiplication. Fix an arbitrary ring homomorphism $\rho:A \rightarrow E$, and assume that $\rho(A)$ is contained in the center of $E$, $Z(E)$. Then, viewing $E$ as a module over itself, via the restriction of scalars

$$\rho^\ast:\lMod{E} \rightarrow \lMod{A}$$

we can consider the $A$-module $\rho^\ast E$ defined through it. Then on $\rho^\ast E$, through the multiplication of $E$, a map $\mu:\rho^\ast E\times \rho^\ast E \rightarrow \rho^\ast E$ is defined, and here

$$\mu(\alpha\cdot x, y)=(\rho(\alpha)x)y=\rho(\alpha)xy$$

and since $\rho(\alpha)\in Z(E)$, through this we can verify the identity

$$\alpha\cdot \mu(x,y)=\mu(\alpha\cdot x,y)=\mu(x,\alpha\cdot y)$$

Here, the ring homomorphism giving $E$ an $A$-algebra structure, $\rho:A \rightarrow E$, is called the *structure morphism*.

::: Definition 2
Let two $A$-algebras $E,E'$ be given. An $A$-module homomorphism $u: E \rightarrow E'$ is called an *$A$-algebra homomorphism* if the equation

$$u(xy)=u(x)u(y)$$

holds for all $x,y\in E$. If $E$ and $E'$ are unital, then an $A$-algebra homomorphism is also understood to be unital; that is, we implicitly assume $u(1)=1$.
:::

Then the following holds.

::: Proposition 3
The composition of $A$-algebra homomorphisms is an $A$-algebra homomorphism. A bijective $A$-algebra homomorphism is always an isomorphism.
:::
::: Proof
That the composition is an $A$-algebra homomorphism is obtained by directly substituting the definition. On the other hand, for a bijective $A$-algebra homomorphism $u:E\rightarrow E'$, the fact that $u^{-1}$ is $A$-linear is a consequence of [§Modules, ⁋Proposition 7](/en/math/algebraic_structures/modules#prop7){: data-relation="required" }, and for any $x,y\in E'$, we have $u(u^{-1}(x)u^{-1}(y))=xy$, so from $u$ being injective we obtain $u^{-1}(xy)=u^{-1}(x)u^{-1}(y)$. Finally, from $u(1)=1$, we have $u^{-1}(1)=1$.
:::

These data define the category of $A$-algebras. In what follows, unless otherwise specified, an $A$-algebra is always assumed to be associative and unital. In particular, an $A$-algebra homomorphism is also unital. Under this convention, we denote the category of associative unital $A$-algebras by $\Alg{A}$, and the category of commutative $A$-algebras by $\cAlg{A}$.

## Examples of Algebras

Just as a free ring is defined on an abelian group, a free algebra is defined on any $A$-module. This process is completely identical to what was done in [§Definition of a Ring, ⁋Proposition 4](/en/math/algebraic_structures/rings#prop4){: data-relation="required" }; upon reflection, this is natural, since the only additional thing we need to show is that the multiplication defined here is compatible with the scalar multiplication structure of $A$, and this is because requiring $A$ to be commutative already defines a scalar multiplication structure on $F(M)=\bigoplus_{n\geq 0}M^{\otimes n}$.

That is, the following holds.

::: Proposition 4
For any $A$-module $M$, if we define

$$F(M)=\bigoplus_{n\geq 0} M^{\otimes n}$$

then $F$ is the left adjoint of the forgetful functor $\Alg{A} \rightarrow \lMod{A}$.
:::

The $F(M)$ resulting from the above proposition is obtained by using the addition, which is data defined on $M$, as is, and defining a new operation, multiplication. On the other hand, using the multiplication defined on a suitable group $G$, it is also possible to make it an $A$-algebra.

::: Definition 5
Fix a (not necessarily commutative) ring $A$ and an arbitrary group $G$. Then, first, as a set, the *group ring* $AG$ is the collection of finitely supported functions from $G$ to $A$, where for two functions $\alpha:G \rightarrow A$, $\beta: G \rightarrow A$, their operations are given by

$$\alpha+\beta: x\mapsto \alpha(x)+\beta(x),\qquad \alpha\beta:x\mapsto \sum_{uv=x}\alpha(u)\beta(v)$$

If $A$ is a (commutative) ring, then $AG$ also carries an $A$-module structure, so it becomes an $A$-algebra. In this case, $AG$ is called the *group algebra*.
:::

For each $x\in G$, if we define $\delta_x: G \rightarrow A$ by the formula

$$\delta_x(y)=\begin{cases}1&\text{if $x=y$}\\0&\text{if $x\neq y$}\end{cases}$$

then any element of $AG$ can be written, for a family indexed by elements of $G$ with $\alpha_x\in A$, as

$$\sum_{x\in G} \alpha_x\delta_x,\qquad\text{$\alpha_x=0$ for all but finitely many $x$}$$

If for convenience we write the function $\delta_x$ as $x$, the multiplication in $AG$ can be written as the formula

$$\left(\sum_{x\in G} \alpha_xx\right)\left(\sum_{y\in G} \beta_yy\right)=\sum_{x,y\in G}\alpha_x\beta_yxy=\sum_{z\in G}\left(\sum_{x\in G}\alpha_x\beta_{x^{-1}z}\right)z$$

Then the following holds.

::: Proposition 6
Consider the two functors

$$A-: \Grp \rightarrow \Alg{A},\qquad (-)^\times:\Alg{A} \rightarrow \Grp$$

Here, $(-)^\times$ is the functor that, given any $A$-algebra $E$, gives the group of units $E^\times$. Then $A{-}\dashv (-)^\times$.
:::
::: Proof
That is, for any group $G$ and $A$-algebra $E$, we must show the following isomorphism:

$$\Hom_{\Alg{A}}(AG, E)\cong \Hom_\Grp(G, E^\times)$$

First, suppose a group homomorphism $f:G \rightarrow E^\times$ is given. Then from this, by the formula

$$\tilde{f}:AG \rightarrow E;\quad \sum_{x\in G} \alpha_x\delta_x\mapsto \sum_{x\in G} \alpha_xf(x)$$

we can define $\tilde{f}:AG \rightarrow E$. That $\tilde{f}$ preserves addition and scalar multiplication follows immediately from the definition, and in the case of multiplication as well, since

$$\begin{aligned}\tilde{f}\left(\left(\sum_{x\in G} a_xx\right)\left(\sum_{y\in G} b_yy\right)\right)&=\tilde{f}\left(\sum_{x,y\in G}a_xb_yxy\right)=\tilde{f}\left(\sum_{z\in G}\left(\sum_{x\in G}a_xb_{x^{-1}z}\right)z\right)\\&=\sum_{z\in G}\left(\sum_{x\in G}a_xb_{x^{-1}z}\right)f(z)=\sum_{x,y\in G} a_xb_yf(xy)\\&=\left(\left(\sum_{x\in G} a_xf(x)\right)\left(\sum_{y\in G} b_yf(y)\right)\right)=\tilde{f}\left(\sum_{x\in G} a_xx\right)\tilde{f}\left(\sum_{y\in G} b_yy\right)\end{aligned}$$

the desired equation holds. Conversely, given any $A$-algebra homomorphism $u: AG \rightarrow E$, the function defined by the formula

$$\bar{u}: G \rightarrow E;\qquad x\mapsto u(\delta_x)$$

preserves multiplication. This is because for any $x,y\in G$,

$$\bar{u}(xy)=u(\delta_{xy})=u(\delta_x\delta_y)=u(\delta_x)u(\delta_y)=\bar{u}(x)\bar{u}(y)$$

holds. Also, since $u$ sends $1_{AG}=\delta_e$ to $1_E$, for any $x\in G$ we have

$$\bar{u}(x)\bar{u}(x^{-1})=u(\delta_x\delta_{x^{-1}})=u(\delta_e)=1_E$$

and therefore the image of $\bar{u}$ lies in $E^\times$. That these two processes are inverses of each other is because $\tilde{f}$ sends $\delta_x$ to $f(x)$, so $\bar{\tilde{f}}=f$, and conversely, because the $\delta_x$ generate $AG$ as an $A$-module, agreeing on the $\delta_x$, the two $A$-algebra homomorphisms $\tilde{\bar{u}}$ and $u$ are equal.
:::

The last example is already somewhat familiar: we revisit what was briefly examined as a ring in [§Graded Rings, ⁋Example 5](/en/math/algebraic_structures/graded_rings#ex5){: data-relation="weak" }, now viewed as an $A$-algebra.

::: Definition 7
For a ring $A$, the *polynomial algebra* $A[\x]$ is, as a set,

$$A[\x]=\{p(\x)=a_n\x^n+\cdots+a_1\x+a_0\mid a_i\in A\}$$

where addition and multiplication are given by polynomial addition and multiplication, and scalar multiplication by $A$ is likewise given by constant multiples of polynomials. More generally, for any set $S$, $A[S]$ can also be defined in a similar manner.
:::

In the case of multivariate polynomials $A[S]$, for notational convenience, it is customary to choose, satisfying $\lvert S\rvert=\lvert I\rvert$, an index set $I$ and set the elements of $S$ as $\x_i$. Then for any

$$\alpha=(\alpha_i)_{i\in I}\in \mathbb{N}_{\geq0}^I\qquad\text{finitely supported}$$

we write

$$\x^\alpha=\prod_{i\in I}\x_i^{\alpha_i}$$

and elements of $A[\x_i]_{i\in I}$ can be written as the following expression:

$$\sum_{d=0}^n \sum_{\lvert\alpha\rvert=d} a_\alpha\x^\alpha,\qquad\text{$a_\alpha=0$ for all but finitely many $\alpha$}$$

Here, $\lvert\alpha\rvert=\sum_{i\in I}\alpha_i$.

Similarly, polynomial algebras also satisfy the following universal property.

::: Proposition 8
Taking a set $S$ and associating, with each element of $S$ as a variable, the polynomial algebra $A[\x_i]_{i\in I}$, the functor $A[-]:\Set \rightarrow \cAlg{A}$ is the left adjoint of the forgetful functor $U: \cAlg{A} \rightarrow \Set$. 
:::
::: Proof
That is, we must show the following isomorphism:

$$\Hom_{\cAlg{A}}(A[\x_i]_{i\in I}, E)\cong\Hom_\Set(S, UE)$$

First, suppose an arbitrary function $f:S \rightarrow U(E)$ is given. Then the map $\tilde{f}: A[\x_i]_{i\in I} \rightarrow E$ defined by the formula

$$\tilde{f}: \sum_{d=0}^n \sum_{\lvert\alpha\rvert=d} a_\alpha\x^\alpha\mapsto \sum_{d=0}^n\sum_{\lvert\alpha\rvert=d}a_\alpha\prod_{i\in I}f(\x_i)^{\alpha_i}$$

is a map from $A[\x_i]_{i\in I}$ to $E$ that is an $A$-algebra homomorphism. Indeed, $\tilde{f}$ is $A$-linear by definition, and on monomials we have $\tilde{f}(\x^\alpha\x^\beta)=\tilde{f}(\x^{\alpha+\beta})=\tilde{f}(\x^\alpha)\tilde{f}(\x^\beta)$, so by distributivity it preserves multiplication, and from the term with $\alpha=0$ we get $\tilde{f}(1)=1$.

Conversely, given any $A$-algebra homomorphism $u:A[\x_i]_{i\in I} \rightarrow E$, we can define $\bar{u}:S \rightarrow UE$ by $\x_i\mapsto u(\x_i)$. That these two correspondences are inverses of each other follows because $\tilde{f}$ sends $\x_i$ to $f(\x_i)$, so $\bar{\tilde{f}}=f$, and conversely, because the $\x_i$ generate $A[\x_i]_{i\in I}$ as an $A$-algebra, as they agree on the $\x_i$, the two $A$-algebra homomorphisms $\tilde{\bar{u}}$ and $u$ are equal.
:::

Thus a polynomial algebra can be thought of as a kind of free commutative $A$-algebra. Comparing [Definition 5](#def5){: data-relation="weak" } and [Definition 7](#def7){: data-relation="weak" } reveals a slight similarity; if we generalize [Definition 5](#def5){: data-relation="weak" } to consider a *monoid ring*, then the polynomial ring of [Definition 7](#def7){: data-relation="weak" } becomes the monoid ring made from the monoid consisting of elements of the form $\x^\alpha$. 

## Subalgebras, Ideals, and Quotient Algebras

::: Definition 9
For an $A$-algebra $E$, a submodule $F$ is called a *subalgebra* of $E$ if $F$ is closed under the multiplication of $E$ and $1\in F$. 
:::

Meanwhile, as defined earlier in [§Definition of a Ring, ⁋Definition 7](/en/math/algebraic_structures/rings#def7){: data-relation="required" }, we also define ideals of an $A$-algebra. 

::: Definition 10
For an $A$-algebra $E$, a submodule $\mathfrak{a}$ is called a *left ideal* of $E$ if for any $x\in \mathfrak{a}$ and $\alpha\in E$ we have $\alpha x\in \mathfrak{a}$. Similarly, a *right ideal* is also defined. A left ideal that is also a right ideal is called a *two-sided ideal*. 
:::

That is, an ideal of an $A$-algebra is nothing special, but simply an ideal of $E$ viewed as a ring, forgetting the $A$-action defined on $E$. Indeed, since $E$ is unital, for any $\alpha\in A$ and $x\in E$ we have $\alpha\cdot x=(\alpha\cdot 1)x$, so an ideal as a ring automatically becomes a submodule. On the other hand, a subalgebra in [Definition 9](#def9){: data-relation="required" } contains $1$, so the only thing that is both an ideal and a subalgebra is $E$ itself. As an example, for an $A$-algebra homomorphism $u:E \rightarrow F$, the kernel

$$\ker u=\{x\in E\mid u(x)=0\}$$

is a two-sided ideal of $E$. Then we can define the following.

::: Definition 11
For any $A$-algebra $E$ and, in $E$, any two-sided ideal $\mathfrak{a}$, we call $E/\mathfrak{a}$ the *quotient algebra* by $\mathfrak{a}$ of $E$. 
:::

Of course, having defined it this way we must prove that $E/\mathfrak{a}$ is an $A$-algebra; but that the ring structure is well-defined is the same as the calculation before [§Quotient Rings and Ring Isomorphisms, ⁋Definition 1](/en/math/algebraic_structures/quotient_rings#def1){: data-relation="required" }, and we only need to add that since $\mathfrak{a}$ is a submodule, on $E$ the $A$-action descends to $E/\mathfrak{a}$. Moreover, the following holds.

::: Proposition 12
For an $A$-algebra homomorphism $u:E \rightarrow F$ and its kernel $\ker u$, the following hold.

1. $\ker u$ is a two-sided ideal of $E$, and $x+\ker u \mapsto u(x)$ defines a well-defined isomorphism $E/\ker u \rightarrow \im u$.
2. For a subalgebra of $E$, $E'$, $E'+\ker u=\{x'+y\mid x'\in E', y\in\ker u\}$ is a subalgebra of $E$, $E'\cap\ker u$ is a two-sided ideal of $E'$, and there exists an isomorphism $(E'+\ker u)/\ker u\cong E'/(E'\cap \ker u)$. 
3. If two two-sided ideals of $E$, $\mathfrak{a}, \mathfrak{b}$, satisfy $\mathfrak{b}\subseteq \mathfrak{a}$, then $\mathfrak{a}/\mathfrak{b}$ is a two-sided ideal of $E/\mathfrak{b}$ and $(E/\mathfrak{b})/(\mathfrak{a}/\mathfrak{b})\cong E/\mathfrak{a}$ holds.
4. For a two-sided ideal of $E$, $\mathfrak{a}$, there exists an inclusion-preserving bijection between the set of two-sided ideals of $E/\mathfrak{a}$ and the set of two-sided ideals containing $\mathfrak{a}$ in $E$.
:::

This is the $A$-algebra version of [§Quotient Rings and Ring Isomorphisms, ⁋Theorem 3](/en/math/algebraic_structures/quotient_rings#thm3){: data-relation="required" }, and its proof proceeds in the same way except that we additionally check that the ring homomorphism obtained there is $A$-linear. The submodule conditions appearing in all four items come from the corresponding subsets being closed under $E$'s $A$-action.
