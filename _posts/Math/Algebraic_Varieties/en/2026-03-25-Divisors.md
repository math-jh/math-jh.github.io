Consider a rational function $$f \in \mathbb{K}(X)$$ defined on a variety $$X$$. This function has zeros at some points and is undefined at others. Essentially, rational functions are of the form of rational expressions, so the points where this function is undefined are a kind of pole, and we can also consider the order of such a pole. To describe this information systematically, we introduce the notion of a *divisor*.

For this to work, for every codimension 1 irreducible subvariety $$Y$$ of $$X$$, the stalk $$\mathcal{O}_{X, \eta_Y}$$ at its generic point $$\eta_Y$$ must be a discrete valuation ring. For this to be well-defined, it suffices that $$X$$ is a normal domain ([[Commutative Algebra] §Integral Extensions, ⁋Definition 3](/en/math/commutative_algebra/integral_extension#def3)), or more generally that the $$R_1$$ condition of [[Commutative Algebra] §Regular Local Rings, ⁋Theorem 11](/en/math/commutative_algebra/regular_local_rings#thm11) is satisfied. However, a variety being normal is not such a difficult condition, and if a variety is not normal, we can avoid this problem by considering the normalization of [[Commutative Algebra] §Regular Local Rings, ⁋Definition 10](/en/math/commutative_algebra/regular_local_rings#def10), so we implicitly understand $$X$$ to be normal in the context where divisors appear.

## Weil Divisors

We first examine the most intuitive definition of a divisor, the *Weil divisor*. This is a formal sum of codimension 1 closed subvarieties with integer coefficients, where the integer coefficient of each term represents the order of the zero or pole at the corresponding closed subvariety.

::: Definition 1
A *Weil divisor* on a variety $$X$$ is a formal $$\mathbb{Z}$$-linear combination of codimension 1 (irreducible) closed subvarieties of $$X$$:

$$D = \sum_{i=1}^{r} n_i Y_i$$

We denote the set of Weil divisors by $$\Div(X)$$.
:::

Then $$\Div(X)$$ forms an abelian group under addition.

::: Definition 2
A Weil divisor $$D = \sum_i n_i Y_i$$ is *effective* if all $$n_i \ge 0$$. We denote this by $$D \ge 0$$.
:::

Meanwhile, as mentioned above, the basic idea of a Weil divisor is to contain information about the zeros and poles of a rational function $$f \in \mathbb{K}(X)^\ast$$. We call this a *principal divisor*.

::: Definition 3
The *principal divisor* $$\divisor(f)$$ of a rational function $$f \in \mathbb{K}(X)^\ast$$ is defined as follows:

$$\divisor(f) = \sum_{Y} v_Y(f) \cdot Y$$

where the sum is over all codimension 1 irreducible closed subvarieties $$Y$$ of $$X$$, and $$v_Y(f)$$ is the integer representing the order of the zero or pole of $$f$$ along $$Y$$.
:::

If $$Y$$ is a smooth subvariety of codimension 1, then in a neighborhood of each point $$x$$ of $$Y$$, $$Y$$ is defined by a single regular function $$\pi$$. We call this $$\pi$$ a *local equation* in a neighborhood of $$P$$. Now expand the rational function $$f$$ in a neighborhood of $$x$$ as $$f = \pi^{v_Y(f)} \cdot u$$. Here, all information about the zeros and poles of $$f$$ is contained in $$\pi^{v_Y(f)}$$, so $$u$$ is a function with neither zeros nor poles in a neighborhood of $$x$$, and $$v_Y(f)$$ is the zero/pole order along $$Y$$.

To define this mathematically rigorously, the stalk $$\mathcal{O}_{X, \eta}$$ of the structure sheaf at the generic point $$\eta$$ of $$Y$$ becomes a discrete valuation ring, and the local equation $$\pi$$ corresponds to a uniformizer of this discrete valuation ring. Then $$v_Y(f)$$ is exactly the valuation of this discrete valuation ring. For this to make sense, the stalk $$\mathcal{O}_{X, \eta}$$ at the generic point of $$Y$$ must be a discrete valuation ring, and this is precisely the reason we take $$X$$ to be a normal variety.

::: Example 4
Consider the regular function $$f(\x, \y) = \x^2 \y$$ defined on $$\mathbb{A}^2$$. This function has no poles, and zeros only along the two irreducible closed subvarieties $$D_1=Z(\x)$$ and $$D_2=Z(\y)$$. At this time, the zero along $$D_1$$ is of order 2, and the zero along $$D_2$$ is of order 1, so the principal divisor corresponding to $$f$$ is

$$\divisor(f)=2D_1+D_2$$
:::

::: Example 5
Consider the rational function on $$\mathbb{A}^1$$

$$g(\x) = \frac{(\x-a_1)^{n_1} \cdots (\x-a_k)^{n_k}}{(\x-b_1)^{m_1} \cdots (\x-b_l)^{m_l}}$$

This function has zeros of order $$n_i$$ along $$a_i$$ and poles of order $$m_j$$ along $$b_j$$, so the principal divisor of this function is

$$\divisor(g) = n_1(a_1) + \cdots + n_k(a_k) - m_1(b_1) - \cdots - m_l(b_l)$$

where $$(a_i)$$ denotes the divisor representing the point $$a_i$$, positive coefficients mean zeros, and negative coefficients mean poles.
:::

::: Proposition 6
$$\divisor: \mathbb{K}(X)^\ast \to \operatorname{Div}(X)$$ is a group homomorphism.
:::
::: Proof
For $$f, g \in \mathbb{K}(X)^\ast$$, for each $$Y$$,

$$v_Y(fg) = v_Y(f) + v_Y(g)$$

so

$$\divisor(fg) = \sum_Y v_Y(fg) \cdot Y = \sum_Y (v_Y(f) + v_Y(g)) \cdot Y = \divisor(f) + \divisor(g)$$
:::

Our goal is to extract properties of $$X$$ from $$\Div(X)$$. However, $$\Div(X)$$ is unnecessarily large for this purpose. Since we know the elements of $$\mathbb{K}(X)^\ast$$ to some extent anyway, we will treat a divisor that can be obtained from a given divisor by adding a divisor coming from an element of $$\mathbb{K}(X)^\ast$$ as the same as the original divisor. That is, we define the following.

::: Definition 7
Two Weil divisors $$D_1, D_2$$ are *linearly equivalent* if there exists a rational function $$f \in \mathbb{K}(X)^\ast$$ such that $$D_1 - D_2 = \divisor(f)$$. We denote this by $$D_1 \sim D_2$$.
:::

Then the following holds.

::: Proposition 8
Linear equivalence $$\sim$$ is an equivalence relation on $$\operatorname{Div}(X)$$.
:::

::: Proof
First, $$D - D = 0 = \divisor(1)$$, so $$D \sim D$$. Also, if $$D_1 \sim D_2$$, then there exists $$f$$ such that $$D_1 - D_2 = \divisor(f)$$, and then for this $$f$$, $$D_2 - D_1 = \divisor(f^{-1})$$. Finally, assume $$D_1 \sim D_2$$ and $$D_2 \sim D_3$$. That is, there exist $$f, g$$ such that $$D_1 - D_2 = \divisor(f)$$ and $$D_2 - D_3 = \divisor(g)$$. Then $$D_1 - D_3 = \divisor(fg)$$, so $$D_1 \sim D_3$$.
:::

::: Definition 9
We define the *divisor class group* $$\Cl(X)$$ of $$X$$ as the quotient group of $$\operatorname{Div}(X)$$ by linear equivalence:

$$\Cl(X) = \operatorname{Div}(X) / \{\divisor(f) : f \in \mathbb{K}(X)^\ast\}$$
:::

To know which elements of $$\Div(X)$$ are the same in $$\Cl(X)$$, it suffices to examine whether a given divisor is linearly equivalent to $$0$$. This is essentially an algebraic geometry translation of [[Algebraic Topology] §Homotopy, ⁋Definition 9](/en/math/algebraic_topology/homotopy#def9). For a fixed space $$X$$ and its subspace $$A$$, $$A$$ is a *deformation retract* of $$X$$ if there exists a continuous function

$$H:[0,1]\times X\rightarrow X$$

satisfying (i) $$H(0, x) = x$$, (ii) $$H(1, x) \in A$$, (iii) if $$a \in A$$ then $$H(t, a) = a$$. That is, at $$t=0$$ the whole of $$X$$ appears, and at $$t=1$$ $$A$$ appears, but $$A$$ itself remains fixed during the deformation. To translate this concept into algebraic geometry, we use $$\mathbb{P}^1$$ as the parameter space instead of $$[0,1]$$. More specifically, if we view an element $$f$$ of $$\mathbb{K}(X)^\ast$$ as a rational map $$X \dashrightarrow \mathbb{P}^1$$, we can consider the graph of this rational map

$$\Gamma_f =\{(x, t)\in X\times \mathbb{P}^1\mid f(x)=t\}\subset X \times \mathbb{P}^1$$

Then pulling back the coordinate of $$\mathbb{P}^1$$ via the canonical projection $$\pr_2:\Gamma_f\rightarrow \mathbb{P}^1$$ gives $$f$$ itself, so $$\divisor(f)$$ measures the difference between the $$t=0$$ section and the $$t=\infty$$ section on $$\Gamma_f$$.

Thus, from this motivation, we can say that $$\Cl(X)$$ is smaller than $$\Div(X)$$, yet still contains information about the properties of $$X$$.

::: Example 10
$$\Cl(\mathbb{A}^n) = 0$$. To verify this, suppose an arbitrary Weil divisor $$D=\sum n_i Y_i$$ is given. We need to show that this is the principal divisor of some function. Since $$Y_i$$ is an irreducible closed subvariety, it corresponds to a prime ideal $$I(Y_i)$$ of the coordinate ring $$\mathbb{K}[\x_1,\ldots, \x_n]$$, and $$\codim Y_i=\codim I(Y_i)=1$$. However, $$\mathbb{K}[\x_1,\ldots, \x_n]$$ is a unique factorization domain by [[Ring Theory] §Polynomial Rings, ⁋Theorem 16](/en/math/ring_theory/polynomial_rings#thm16), so any height 1 prime ideal is necessarily principal. That is, there exists a function $$f_i\in \mathbb{K}[\x_1,\ldots, \x_n]$$ such that $$I(Y_i)=(f_i)$$, and from this each $$Y_i$$ is $$Z(f_i)$$.
:::

Of course, to know what kind of information $$\Cl(X)$$ contains, we should consider the case where $$\Cl(X)\neq 0$$.

::: Example 11
$$\Cl(\mathbb{P}^n) \cong \mathbb{Z}$$. To verify this, let us take an arbitrary hyperplane class, say $$H=Z(\x_0)$$, as a reference. We will first show that a hyperplane $$Z(F)$$ defined by an arbitrary degree $$d$$ homogeneous polynomial $$F$$ equals $$dH$$. To verify this, consider the function $$F/\x_0^d\in \mathbb{K}(\mathbb{P}^n)^\ast$$, then

$$\divisor(F/\x_0^d)=\divisor(F)-d\cdot \divisor(\x_0)=Z(F)-dH$$

Therefore, a Weil divisor $$D=\sum n_i Y_i$$ is determined by the order $$n_i$$ and the degree $$d_i$$ of the homogeneous polynomial defining $$Y_i$$. Taking this as intuition, we define the following map

$$\deg: \Cl(\mathbb{P}^n) \rightarrow \mathbb{Z};\qquad D=\sum n_i Y_i \mapsto \sum n_i \deg(Y_i)$$

where $$\deg(Y_i)$$ is the degree of the homogeneous polynomial defining $$Y_i$$. At this time, since every hypersurface is the zero set of some homogeneous polynomial, there is no problem in defining it this way. Also, by [[Rational Maps] §Example 4](/en/math/algebraic_varieties/rational_maps#ex4), we know that any rational function on $$\mathbb{P}^n$$ is represented as a ratio $$F/G$$ of homogeneous polynomials $$F,G$$ of the same degree, so for a principal divisor $$\divisor(F)$$, $$\deg(\divisor(F))=0$$ necessarily holds, and thus this definition is well-defined.

Our claim is that $$\deg$$ is an isomorphism. First, $$\deg$$ being surjective is obvious since the image of $$dH$$ goes to $$d$$. For injectivity, we need to show that a $$D$$ satisfying $$\deg(D)=0$$ is a principal divisor. However, we have already seen that $$D \sim dH$$, so for this to map to $$0$$ via the $$\deg$$ map, we must have $$d=0$$. That is, $$D$$ is linearly equivalent to $$0$$.

Intuitively, the reason this differs from $$\mathbb{A}^n$$ is that global regular functions defined on $$\mathbb{P}^n$$ are constant functions. That is, if a function defined on $$\mathbb{P}^n$$ has a zero at a certain point, then this function must necessarily have a pole at another point, and the sum of the orders of the zeros must equal the sum of the orders of the poles. The fact that $$\Cl(\mathbb{P}^n)\cong \mathbb{Z}$$ means that the $$dH$$ with $$d\neq 0$$ are essentially all non-principal divisors of $$\mathbb{P}^n$$, and the remaining divisors $$\sum n_i D_i$$ are merely distributing this order $$d$$ to each $$D_i$$ via a rational function $$f$$.
:::

## Cartier Divisors

Weil divisors are geometrically intuitive, but have the problem of not working well on singular varieties. For example, on the cone $$X=Z(\x^2 + \y^2 - \z^2) \subset \mathbb{A}^3$$, imagine defining a principal divisor following the explanation after [Definition 3](#def3). At a smooth point of this cone, say $$(1,0,1)$$, consider a codimension $$1$$ subvariety, say $$X\cap Z(\y)$$. This subvariety is defined by the local equation $$\y=0$$ in a neighborhood of this point, so for any given rational function $$f$$, we can extract information about zeros and poles with respect to $$\y$$ here. The problem occurs at the singular point. For example, consider the codimension $$1$$ subvariety $$L=(t,0,t)$$ in a neighborhood of the origin $$(0,0,0)$$. To represent this, both equations $$\y=0$$ and $$\x-\z=0$$ are needed, which means we cannot well-define $$v_L(f)$$. More rigorously, $$\mathcal{O}_{X,(0,0,0)}$$ is not a (dimension $$1$$) regular local ring and thus not a discrete valuation ring either, so we cannot define a valuation in the first place.

That is, the core problem is that on a singular variety, there are cases where a codimension $$1$$ subvariety cannot be expressed locally by a single equation. Therefore, we simply restrict our attention to objects that can be expressed locally by a single equation. As always, we define this via an appropriate kind of gluing.

::: Definition 12
A *Cartier divisor* on a variety $$X$$ is the following data:

$$\{(U_i, f_i)\}_{i \in I}$$

where $$\{U_i\}$$ is an open cover of $$X$$, each $$f_i \in \mathbb{K}(X)^\ast$$ is a nonzero rational function, and for all $$i, j$$, $$f_i/f_j$$ is regular and non-vanishing (hence invertible) on $$U_i \cap U_j$$.

In this case, for two data $$\{(U_i, f_i)\}$$ and $$\{(V_j, g_j)\}$$, if there exists a refinement $$\{W_k\}$$ of the two open covers such that $$f_i/g_j$$ is regular and non-vanishing on it, then these two data are regarded as representing the same Cartier divisor.
:::

By definition, a Cartier divisor is a collection of only locally principal codimension 1 subvarieties. The data $$U_i$$ explicitly specifies exactly which open set is local, and by which single function it is defined on that open set. According to this, the line $$L$$ examined above cannot be expressed by a single equation on an open set in a neighborhood of the origin, so it is not a Cartier divisor.

::: Example 13
In the example of the cone above, consider the line $$L'=(t,0,-t)$$. This is not a Cartier divisor for the same reason as $$L$$. However, their sum $$L+L'$$ is a Cartier divisor, because $$L+L'$$ is defined by the zero set of $$\y$$.
:::

As mentioned above, a Cartier divisor can be thought of as a codimension 1 subvariety with the additional locally principal condition. Specifically, if a Cartier divisor $$\{(U_i, f_i)\}$$ is given, we can consider the principal Weil divisor $$\divisor(f_i)$$ of $$f_i$$ on each $$U_i$$. Since $$f_i/f_j$$ is invertible on $$U_i \cap U_j$$, $$v_Y(f_i)=v_Y(f_j)$$ holds for all codimension $$1$$ subvarieties $$Y$$, and thus we can glue these together to define a Weil divisor.

The opposite direction does not generally hold, as we saw above, but at the same time we can see that there is no problem in the smooth case since the stalk becomes a regular local ring. That is, the following holds.

::: Proposition 14
On a smooth variety $$X$$, Weil divisors and Cartier divisors naturally correspond one-to-one.
:::

Essentially, a Weil divisor plays a role similar to a homology class, namely certain subsets of the space $$X$$, while a Cartier divisor, by its definition, plays a role similar to a cohomology class, namely functions defined (locally) on the space $$X$$. From this perspective, this proposition can be thought of as a kind of Poincaré duality. ([[Algebraic Topology] §Poincaré Duality, ⁋Theorem 11](/en/math/algebraic_topology/Poincare_duality#thm11))

Now we also define linear equivalence and the divisor class group for Cartier divisors, just as we did for Weil divisors. To do so, we first need the following.

::: Definition 15
For a rational function $$f \in \mathbb{K}(X)^\ast$$, the *principal Cartier divisor* $$\divisor(f)$$ is defined as $$\{(X, f)\}$$.
:::

Then the following definition is the Cartier version of [Definition 7](#def7).

::: Definition 16
Two Cartier divisors $$D_1, D_2$$ are *linearly equivalent* if $$D_1 - D_2$$ is a principal divisor.
:::

We denote the group of Cartier divisors by $$\CaDiv(X)$$, and the subgroup generated by principal divisors by $$\Prin(X)$$. Then the *Cartier divisor class group* is

$$\CaCl(X) = \CaDiv(X) / \Prin(X)$$

By [Proposition 14](#prop14), on a smooth variety $$\CaCl(X) \cong \Cl(X)$$.
