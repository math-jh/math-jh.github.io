## Introduction

To understand what ordinals are, it is helpful to examine the following *Peano axioms* that define the natural numbers.

::: misc Peano Axioms. {#peano-axioms}
The set of natural numbers $\mathbb{N}$ and the *successor function* $S$ defined on this set are objects that satisfy the following axioms:

1. $0$ is a natural number.
2. For any natural number $n$, $S(n)$ is also a natural number.
3. $S$ is injective.
4. $S(n)=0$ is satisfied by no natural number $n$.
5. If, containing $0$, another set $K$ is closed under $S$, then $K$ contains $\mathbb{N}$.
:::

Mathematical induction, as we commonly use it, is in fact a proposition derived from the above axioms. In standard set theory textbooks (such as **[HJJ]**, which we used when defining the ZFC axioms and ordered pairs), operations on natural numbers are defined at this point using the following recursion theorem.

::: Theorem 1 (The recursion theorem)
Let a set $A$ be given. For an element $a\in A$ of this set and an arbitrary function $g:A\times \mathbb{N}\rightarrow A$, there exists, satisfying the following conditions:

1. $f_0=a$,
2. for all $n\in\mathbb{N}$, $f_{n+1}=g(f_n,n)$,

a unique infinite sequence $f:\mathbb{N}\rightarrow A$.
:::
::: Proof
We only briefly introduce the idea of the proof. Define an *$m$-step computation*, satisfying the condition

$$t_0=a,\quad t_{k+1}=g(t_k,k)\text{ for all }k< m$$

as a finite sequence $t:\left\{0,1,\cdots,m\right\}\rightarrow A$. Then it is clear that $t$ is a subset of $\mathbb{N}\times A$. Now, for the following set

$$\mathfrak{F}=\left\{t\in\mathcal{P}(\mathbb{N}\times A)\mid t\text{ is an }m\text{-step computation for some natural number }m\right\}$$

let $F=\bigcup\mathfrak{F}$. Then

1. For any $m,n$, one can show that an $m$-step computation and an $n$-step computation are compatible, and through this show that $F$ is a function.
2. We then show that $\pr_1F=\mathbb{N}$ and $\pr_2F\subseteq A$. In this process, induction must be used.
3. By 1 and 2, since we know that $f=(F,\mathbb{N},A)$ is a function, it suffices to show that this function satisfies the given two conditions.
4. Finally, for uniqueness, after assuming that some $h:\mathbb{N}\rightarrow A$ satisfies the conditions of the theorem, it suffices to show using induction that $f_n=h_n$ holds for all $n$.
:::

Within the axiom system we have been working with, there is no way to prove the existence of the set of natural numbers, or more generally, of infinite sets. Therefore, we need to introduce the following axiom.

::: misc The Axiom of infinity {#axiom-infinity}
Containing $0$ and closed under the successor function, a set $I$ exists.
:::

## Natural Numbers and Ordinals

Von Neumann presented a specific model of the natural numbers $\mathbb{N}$ satisfying the Peano axioms above, which serves as good motivation for defining ordinals, so we introduce it first. Von Neumann's idea is to define a natural number $n$ as *a set with $n$ elements*. Then 0 can only be defined uniquely:

$$0=\emptyset.$$

After that, to define $1$, we must create a set with one element. However, since the only set we currently have is $\emptyset$, there is also only one reasonable way to define $1$:

$$1=\{\emptyset\}.$$

We then define $2$ by the following formula

$$2=\{0,1\}=\big\{\emptyset,\{\emptyset\}\big\}$$

and define $3=\{0,1,2\}$ and so on in the same manner. In this model, one can easily verify that $S$ is defined by the function

$$S(x)=x\cup\{x\}$$

By definition, $m<n$ is equivalent to $m\in n$. First, repeating this process yields the set of natural numbers. When treating the set of natural numbers as an ordinal in this way, we write it as $\omega$.

However, the above process does not end simply because we have obtained $\omega$. For instance,

$$S(\omega)=\{0,1,2,\ldots,\omega\}$$

is different from any of the existing sets.[^1] Let us call this $\omega+1$. By repeatedly applying $S$ in this manner, we obtain

$$S(\omega)=\omega+1,\qquad S(\omega+1)=\omega+2, \ldots$$

and continuing to repeat this, we again obtain

$$\omega+1,\omega+2, \ldots, \omega+\omega:=\omega\cdot 2$$

Repeating this again, we obtain $\omega\cdot 2, \omega\cdot 2+1, \ldots, \omega\cdot 3, \ldots,$ and repeating this again, we will finally even obtain $\omega\cdot\omega=\omega^2$; repeating this yet again yields $\omega^3, \ldots, \omega^\omega$, then $\omega^{\omega^{\omega}}, \ldots$. Of course, once this process finishes, if we assign a new symbol to this set, we can repeat the same process again.

## Well-Ordered Sets

The above discussion is intuitive, but not sufficiently rigorous to be accepted as a definition.

::: Definition 2
Defined on a set $A$, a total order $R$ is a *well-ordering* if every non-empty subset of $A$, $X$, has a least element.
:::

::: Example 3
$\mathbb{N}$ is a well-ordered set, but $\mathbb{R}$ is not.

The entire set having a least element is not a sufficient condition for a set to be well-ordered. For example, $\mathbb{R}^{\geq 0}$ has the least element $0$, but its subset $\mathbb{R}^{>0}$ has no least element. Also, since $\mathbb{Z}$ is not well-ordered, the size of the set does not affect this either.
:::

::: Definition 4
Let $(A,\leq)$ be an ordered set. If a subset of $A$, $S$, satisfies the following condition:

> If $x\in S$, $y\in A$, and $y\leq x$, then $y\in S$.

then it is called an *initial segment* of $A$.
:::

In most cases, an initial segment is also simply abbreviated to *segment*.

::: Proposition 5
Let $(A,\leq)$ be a well-ordered set. Every segment of $A$ other than $A$ itself is, for some $a\in A$, of the form $(-\infty, a)$.
:::
::: Proof
Let $S\neq A$ be an arbitrary segment. Since the set $A$ is well-ordered, $A\setminus S$ also has a least element; call it $a$. By definition, every element of $A\setminus S$ is greater than or equal to $a$, so $A\setminus S$ is a subset of $[a,\infty)$.

Now, it only remains to show that $A\setminus S$ is *exactly* $[a,\infty)$, for then $S=(-\infty, a)$ and the proof is complete. Suppose, for contradiction, that some $x\in [a,\infty)$ is not an element of $A\setminus S$. That is, $x$ is an element satisfying both $a\leq x$ and $x\in S$. But since $S$ is a segment, $a\leq x$ implies $a\in S$, and since this contradicts the assumption that $a$ is the least element of $A\setminus S$, we must have $x\not\in S$. Therefore, $A\setminus S$ is exactly $[a,\infty)$, and the proof is complete.
:::

::: remark Remark {#rmk}
The above proposition does not say that the set $(-\infty, a]$ cannot be a segment of $A$. This proposition means that if $(-\infty, a]$ is a segment of $A$, then for some $a'\in A$, this set can also be written in the form $(-\infty, a')$.  

For example, in $\mathbb{N}$, the set $(-\infty, 3]$ is by definition $\{0,1,2,3\}$. The preceding proposition does not mean that this set is not a segment, but rather that this set can also be written as $(-\infty, 4)$.  
:::

Of course, this need not hold for general ordered sets. For instance, $\mathbb{R}$ is not well-ordered, and its segment $(-\infty, a]$ cannot be written in the form $(-\infty, a')$.

In any case, the set $(-\infty, a)$ is always a segment of an ordered set. This set is called the segment with endpoint $a$ and is denoted by $S_a$. For any totally ordered set $A$, the following holds:

$$\bigcup_{a\in A}S_a=\begin{cases}A&\text{if there is no greatest element of $A$}\\ A\setminus\{b\}&\text{if }b\text{ is the greatest element of $A$}\end{cases}.$$

However, in no case does a segment of the form $(-\infty, a)$ contain $a$, so no segment of $A$ having this form can be $A$ itself.
