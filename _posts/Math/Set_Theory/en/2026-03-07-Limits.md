In fact, the material we are about to cover is generally more natural in category theory or algebraic geometry than in set theory. However, **[Bou]** also treats this material in set theory, and since it makes good sense from the perspective of collecting what we will use going forward, we too now look at inverse limits and direct limits.

## Inverse Systems and Inverse Limits

::: Definition 1
Let $I$ be a preordered set, and let a family $(A_i)_{i\in I}$ be given. If, in addition, whenever $i\leq j$, for each pair $(i,j)$ a function $f_{ij}:A_j\rightarrow A_i$ is defined and satisfies the following two conditions:

1. if $i\leq j\leq k$, then $f_{ik}=f_{ij}\circ f_{jk}$,
2. for each $i\in I$, $f_{ii}=\id_{A_i}$,

then $\bigl((A_i)_{i\in I}, (f_{ij})_{i\leq j}\bigr)$ is called an *inverse system*, or a *projective system*.
:::

In **[Bou]**, as in the definition above, no condition other than being a preordered set is imposed on $I$, but considering the directed systems we will look at shortly, it is somewhat more natural to consider the case where $I$ is a *right directed set*, and indeed, most examples we encounter in practice are cases where $I$ is a right directed set.

We have already introduced universal properties when defining sums and products of sets, and we have also seen a bit of how powerful a tool they are. Inverse limits and direct limits are also defined via universal properties.

::: Definition 2
To say that a set $\varprojlim A_i$ and a family of functions $f_i: \varprojlim A_i\rightarrow A_i$, $(f_i)_{i\in I}$, is the *inverse limit* or *projective limit* of $\bigl((A_i)_{i\in I}, (f_{ij})_{i\leq j}\bigr)$ means that for any $i\leq j$,

$$f_i=f_{ij}\circ f_j$$

holds, and additionally, the following universal property is satisfied:

{% diagram Math/Set_Theory/Limits-1.svg width="12.45em" alt="universal_property_of_inverse_limit" %}

> If a set $B$ and a family of functions $u_i:B\rightarrow A_i$ are given such that for each $i\leq j$, the equation
> 
> $$u_i=f_{ij}\circ u_j$$
>
> holds, then there exists a unique function $u:B\rightarrow \varprojlim A_i$ such that for all $i\in I$,
> 
> $$u_i=f_i\circ u$$ 
> 
> holds.
:::

As we mentioned when introducing the universal properties of sums and products of sets, for this definition to make sense, we must directly show that at least one $\bigl(\varprojlim A_i, (f_i)_{i\in I}\bigr)$ exists.

To this end, let us first consider the set $\prod_{i\in I} A_i$ and the projection functions $(\pr_i)_{i\in I}$. Afterward, define the set $A$ by the condition

$$\pr_i x=f_{ij}(\pr_j x)$$

for all $i\leq j$, as the subset of all $x$ satisfying this, and also define the $f_i$ as $\pr_i\vert_{A}$. Then $\bigl(A, (f_i)\bigr)$ defined in this way satisfies the universal property above.

::: Example 3
For example, if $I$, equipped with the usual $\leq$, were $\mathbb{N}$, then the inverse system would look like[^1]

$$\cdots\overset{f_{3,4}}{\rightarrow} A_3\overset{f_{2,3}}{\rightarrow}A_2\overset{f_{1,2}}{\rightarrow}A_1\overset{f_{0,1}}{\rightarrow}A_0$$  

and in this case the set $A$ defined above is the collection of infinite tuples

$$(x_0, x_1,\ldots )\in A_0\times A_1\times\cdots=\prod_{i\in\mathbb{N}} A_i$$

where these tuples satisfy $f_{i, i+1}(x_{i+1})=x_i$, and the $f_i$ are simply the projection functions restricted to $A$.
:::

::: Example 4
Suppose that on an arbitrary index set $I$, the ordering is given by $=$. Then the only functions between them are of the form $f_{ii}=\id_{A_i}$. Therefore, in the construction above,

$$\pr_i(x)=f_{ij}(\pr_j(x))$$

holds trivially for all $i\leq j$, so $A$ becomes the entire $\prod A_i$. Thus in this case, $\varprojlim A_i=\prod A_i$.
:::

In many cases, inverse systems appear in the form shown in [Example 3](#ex3){: data-lid="vdh3g" }. Now, as promised, let us prove the following lemma that supports [Definition 2](#def2){: data-lid="rw9ec" }.

::: Lemma 5
The $\bigl(A, (f_i)\bigr)$ constructed above satisfies the universal property of the inverse limit.
:::
::: Proof
First, if there exists, satisfying the condition

$$u_i=f_i\circ u\qquad\text{for all $i\in I$}$$

a function $u:B\rightarrow A$, then it is not difficult to show that such a $u$ is unique. Suppose $v:B\rightarrow A$ satisfies the same condition. Since $u(y)$ and $v(y)$ are both elements of $\prod A_i$, they are determined by their images under the component functions $\pr_i$. Therefore, applying to $u(y)$ the projection $\pr_i$, we obtain

$$\pr_i(u(y))=f_i(u(y))=u_i(y)=f_i(v(y))=\pr_i(v(y))$$

and therefore $u(y)=v(y)$.

From the uniqueness proof, we see that $u$ must be defined by the formula

$$u(y)=\big(u_i(y)\big)_{i\in I}$$

If defined this way, that $u$ is a function is obvious, so we only need to show that the image of $u$ actually belongs to $A$. That is, we must show that

$$\pr_i(u(y))=f_{ij}(\pr_j(u(y)))$$

holds. But since $\pr_i(u(y))=u_i(y)$, the above equation becomes precisely the given condition

$$u_i(y)=f_{ij}(u_j(y))$$

which gives $u(y)\in A$, completing the proof.
:::

The following corollary showing the uniqueness of the inverse limit is, as always, a formal theorem obtained from the universal property.

::: Corollary 6
The inverse limit of $\bigl((A_i), (f_{ij})\bigr)$ is unique up to bijection.
:::

Furthermore, one can prove various propositions using the universal property. First, let us establish the following definition.

::: Definition 7
Suppose two inverse systems $\bigl((A_i), (f_{ij})\bigr)$ and $\bigl((B_i), (g_{ij})\bigr)$ are given. Then, that a family of functions $u_i:A_i\rightarrow B_i$, $(u_i)_{i\in I}$, is a *morphism of inverse systems* means that for any $i\leq j$, the equation

$$g_{ij}\circ u_j=u_i\circ f_{ij}$$

holds.
:::

That is, the following diagram commutes for all $i\leq j$:

{% diagram Math/Set_Theory/Limits-2.svg width="7.11em" alt="inverse_system_of_mappings" %}

::: Proposition 8
Suppose two inverse systems $\bigl((A_i), (f_{ij})\bigr)$, $\bigl((B_i), (g_{ij})\bigr)$, and a morphism of inverse systems $(u_i:A_i\rightarrow B_i)$ are given. Then there exists a unique $u:\varprojlim A_i\rightarrow \varprojlim B_i$ such that for each $i$, $g_i\circ u=u_i\circ f_i$ holds.

{% diagram Math/Set_Theory/Limits-3.svg width="13.58em" alt="mapping_between_inverse_limits" %}
:::

In other words, if the $u_i$ satisfy appropriate conditions, they naturally induce a function $u$ between inverse limits.

::: Proof (Proposition 8)
First, observe that the composite function $u_i\circ f_i$ defines a function from $\varprojlim A_i$ to $B_i$. Therefore, if we show that these functions satisfy the condition for the universal property to apply, we can well define the function $u$. That is, we must show that

$$(u_i\circ f_i)=g_{ij}\circ (u_j\circ f_j)$$

holds. But since the $u_i$ are a morphism of inverse systems, by the previous definition,

$$g_{ij}\circ u_j=u_i\circ f_{ij}$$

holds, and therefore

$$g_{ij}\circ (u_j\circ f_j)=(u_i\circ f_{ij})\circ f_j=u_i\circ f_i$$

holds. Therefore, to have for all $i\in I$

$$(u_i\circ f_i)=g_i\circ u$$

there exists a unique function $u:\varprojlim A_i\rightarrow\varprojlim B_i$, and this equation is precisely what we wanted.
:::

Therefore, with a slight abuse of notation, such a function $u$ is also written as $u=\varprojlim u_i$. Meanwhile, by the uniqueness obtained as a result of the previous proposition, the following also holds.

::: Corollary 9
Suppose three inverse systems $\bigl((A_i), (f_{ij})\bigr)$, $\bigl((B_i), (g_{ij})\bigr)$, and $\bigl((C_i), (h_{ij})\bigr)$ are given, and let morphisms $(u_i:A_i\rightarrow B_i)$, $(v_i:B_i\rightarrow C_i)$ between these systems be given. Then

$$\varprojlim(v_i\circ u_i)=\bigl(\varprojlim v_i\bigr)\circ\bigl(\varprojlim u_i\bigr)$$

holds.
:::

::: Definition 10
Let an inverse system $\bigl((A_i), (f_{ij})\bigr)$ be given. If, for the $A_i$, subsets $X_i$ are given such that an inverse system can be formed by restricting $f_{ij}$ to them, that is, if the condition

$$f_{ij}(X_j)\subseteq X_i$$

holds for each $i\leq j$, then this system $\bigl((X_i), (f_{ij}\vert_{X_j})\bigr)$ is called an inverse system of subsets of the original system.
:::

Then it is not difficult to verify that

$$\varprojlim X_i=\bigl(\varprojlim A_i\bigr)\cap\prod_{i\in I} X_i$$

holds.

The reason for making such a definition is for the following proposition.

::: Proposition 11
Suppose two inverse systems $\bigl((A_i), (f_{ij})\bigr)$, $\bigl((B_i), (g_{ij})\bigr)$, and a function $(u_i:A_i\rightarrow B_i)$ between inverse systems are given. For convenience, let $u=\varprojlim u_i$. Then, for each $y=(y_i)\in \varprojlim B_i$, the $u_i^{-1}(y_i)$ form an inverse system of subsets of $A_i$, and the inverse limit is given by

$$\varprojlim u_i^{-1}(y_i)=u^{-1}(y)$$
:::
::: Proof
First, let us show that the $u_i^{-1}(y_i)$ form an inverse system of subsets of $A_i$. That is, for any $x_j\in u_j^{-1}(y_j)$, we must show that the value obtained by sending it via $f_{ij}$ to $A_i$ belongs to $u_i^{-1}(y_i)$. That is, it suffices to show that $y_i=u_i(f_{ij}(x_j))$. By direct calculation,

$$u_i(f_{ij}(x_j))=g_{ij}(u_j(x_j))=g_{ij}(y_j)=y_i$$

holds, so this claim holds.

On the other hand, that $x\in\varprojlim A_i$ satisfies $u(x)=y$ means, by the definition of $u$, precisely that $u_i(x_i)=y_i$ holds for all $i$, so the second claim also holds.
:::

Therefore, if all $u_i$ are injective, $u$ must also be injective.

## Directed Systems and Direct Limits

::: Definition 12
Let $I$ be a right directed set, and let a family $(A_i)_{i\in I}$ be given. If, in addition, for each $i\leq j$, the pair $(i,j)$ has a function $f_{ij}:A_i\rightarrow A_j$ defined such that the following two conditions:

1. If $i\leq j\leq k$, then $f_{ik}=f_{jk}\circ f_{ij}$,
2. For each $i\in I$, $f_{ii}=\id_{A_i}$.

are satisfied, then $\bigl((A_i)_{i\in I}, (f_{ij})_{i\leq j}\bigr)$ is called a *directed system*.
:::

Unlike an inverse system, a directed system has a right directed set as its index set. Instead, in an inverse system the functions $f_{ij}$ are defined to go from sets with larger indices to sets with smaller indices, whereas in a directed system the functions $f_{ij}$ are defined to go from smaller indices to larger indices.

::: Definition 13
A set $\varinjlim A_i$ and a family of functions $f_i: A_i\rightarrow \varinjlim A_i$, $(f_i)_{i\in I}$, are called the *direct limit* or *injective limit* of $\bigl((A_i)_{i\in I}, (f_{ij})_{i\leq j}\bigr)$ if for every $i\leq j$,

$$f_i=f_j\circ f_{ij}$$

holds, and additionally, the following universal property is satisfied:

{% diagram Math/Set_Theory/Limits-4.svg width="12.45em" alt="universal_property_of_direct_limit" %}

> If a set $B$ and a family of functions $u_i:A_i\rightarrow B$ are given such that for each $i\leq j$, the equation
> 
> $$u_j\circ f_{ij}=u_i$$
>
> holds, then there exists a unique function $u:\varinjlim A_i\rightarrow B$ such that for all $i\in I$,
> 
> $$u_i=u\circ f_i$$ 
> 
> holds.
:::

To construct an object and functions having these properties, it is necessary to use other objects that are already known. For a collection of sets $A_i$, let $S=\sum A_i$. Via the inclusion $A_i\hookrightarrow S$, if we identify $A_i$ with its image, then for any $x\in S$, we have $x\in A_i$ for a unique index $i$. Let us denote this by $\lambda(x)$. Then the relation

> $x\mathrel{R} y$ means that, for $i=\lambda(x)$ and $j=\lambda(y)$, there exists $k$ greater than or equal to both such that $f_{ik}(x)=f_{jk}(y)$ is satisfied.

can be easily verified to be an equivalence relation. Therefore, the quotient set $A=S/R$ is well-defined, and the natural composition

$$f_i: A_i\hookrightarrow S\twoheadrightarrow S/R=A$$

is also given.

::: Lemma 14
The $\bigl(A, (f_i)\bigr)$ constructed above satisfies the universal property of the direct limit.
:::

Without difficulty, the theorems we examined while defining inverse limits can also be introduced for direct limits. Rather than repeating them, it is more efficient to introduce a particularly frequently used example.

::: Example 15
Let two sets $A,B$ be given. For a directed set $I$, choose a family of subsets of $A$, $(A_i)$, such that the condition

$$i\leq j\iff A_j\subseteq A_i$$

is satisfied. For each $i$, let the set $F_i$ be the collection of functions from $A_i$ to $B$. Then, whenever $i\leq j$, for each $A_i,A_j$, a natural function $f_{ji}:F_i\rightarrow F_j$ can be defined by the formula

$$f_{ji}(u)=u\vert_{A_j}$$

In such situations, the elements of $\varinjlim F_i$ are commonly called *germs*.
:::
