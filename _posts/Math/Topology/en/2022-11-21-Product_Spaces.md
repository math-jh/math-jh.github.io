## Definition and Properties of Product Spaces

::: Definition 1
Let a family of topological spaces $(X_i)_{i\in I}$ be given. Their *product* is the topological space on the product set $X=\prod_{i\in I}X_i$ equipped with the initial topology with respect to the functions $\pr_i:X\rightarrow X_i$.
:::

Then by [§Initial and Final Topology, ⁋Proposition 2](/en/math/topology/initial_and_final_topology#prop2){: data-lid="jexxp" }, the product topology given on $X$ is the space generated with the following set

$$\mathcal{S}=\{\pr_i^{-1}(U_i)\mid U_i\text{ open in }X_i\}$$

as a subbase. Here, the base generated by $\mathcal{S}$, $\mathcal{B}$, is the collection of

$$\prod_{i\in I} U_i,\qquad \text{$U_i$ open in $X_i$, $U_i=X_i$ for all but finitely many $i$}$$

. 

For the same reason as in [\[Set Theory\] §Properties of Products, ⁋Proposition 3](/en/math/set_theory/property_of_products#prop3){: data-lid="xnb41" }, one can see that taking products of spaces is associative, and similarly there is also a proposition concerning the commutative law. Since these are fairly obvious propositions, we do not mention them separately before moving on.

On the other hand, applying [§Initial and Final Topology, ⁋Proposition 3](/en/math/topology/initial_and_final_topology#prop3){: data-lid="ckunt" }, we obtain the following.

::: Proposition 2
Let a product space $X=\prod_{i\in I}X_i$ and a topological space $Y$ be given, and suppose functions $f_i:Y\rightarrow X_i$ are given. Then the function $f=(f_i): Y\rightarrow X$ is continuous if and only if each $f_i$ is continuous.
:::

From this we obtain the following two corollaries. 

::: Corollary 3
With a common index set $I$, suppose two product spaces $X=\prod_{i\in I}X_i$, $Y=\prod_{i\in I}Y_i$ are given, and suppose $f_i:X_i\rightarrow Y_i$ are given. Also suppose that each $X_i$ is non-empty. Then $f:(x_i)\mapsto (f_i(x_i))$ is continuous if and only if each $f_i$ is continuous.
:::

For arbitrary sets $X, Y$ and a function $f:X \rightarrow Y$, the *graph* of $f$, $\graph(f)$, is given by the subset of $X\times Y$

$$\graph(f)=\{(x,f(x))\mid x\in X\}\subseteq X\times Y$$

. If $X, Y$ were both topological spaces, then $\graph(f)$ inherits the subspace topology from the product space $X\times Y$.

::: Corollary 4
For topological spaces $X,Y$ and a function $f:X\rightarrow Y$, $f$ is continuous if and only if the function $g:x\mapsto (x,f(x))$ is a homeomorphism from $X$ to $\graph(f)$.
:::

Moreover, we also know the obvious inverse function of the above function $g$,

$$\pr_X\vert_{\graph(f)}:\graph(f) \rightarrow X$$

. 

In particular, since the constant function sending every point of $X$ to $y_0\in Y$ is continuous, by the above corollary we obtain the homeomorphism

$$X\rightarrow X\times\{y_0\}$$

. On the other hand, consider in $X\times Y$ an arbitrary subset $A$. Then 

$$A\cap (X\times \{y_0\})=\{(x,y)\mid (x,y)\in A,\quad y=y_0\}=\{(x,y_0)\mid (x,y_0)\in A\}$$

. Now, since $X\times\{y_0\}$ is equipped with the subspace topology of $X\times Y$, the above set, if $A$ is an open set of $X\times Y$, is an open set of $X\times\{y_0\}$, and if $A$ is a closed set of $X\times Y$, is a closed set of $X\times\{y_0\}$. Therefore, applying [Corollary 4](#cor4){: data-lid="ow5ei" } again and sending the above set to $X$, the corresponding set is also an open set or a closed set. Let us write this set as $A(y_0)\subseteq X$. Of course, by a similar argument with the roles of $X$ and $Y$ interchanged, we can also obtain in $Y$ a subset $A(x_0)$. 

::: Proposition 5
For an arbitrary open set in $X\times Y$, $U$, $\pr_X(U)$ and $\pr_Y(U)$ are open sets in $X,Y$.  
:::
::: Proof
By the above argument, each $U(y)$ is an open set in $X$ and each $U(x)$ is an open set in $Y$. Therefore, by the equations

$$\pr_X(U)=\bigcup_{y\in Y} U(y),\qquad \pr_Y(U)=\bigcup_{x\in X} U(x)$$

and the fact that an arbitrary union of open sets is an open set, $\pr_X(U)$ and $\pr_Y(U)$ are open sets. 
:::

However, since an arbitrary union of closed sets need not be closed, the claim obtained by replacing $U$ with a closed set in the above proposition does not hold. On the other hand, by [Corollary 4](#cor4){: data-lid="bjrg2" }, we also obtain the following proposition.

::: Proposition 6
If a function $f:X_1\times X_2 \rightarrow Y$ is continuous at $(a_1,a_2)\in X_1\times X_2$, then, defined by the expressions

$$x_1\mapsto f(x_1, a_2),\qquad x_2\mapsto f(a_1,x_2)$$

the functions from $X_1$ to $Y$ and from $X_2$ to $Y$ are continuous at the points $x_1=a_1$ and $x_2=a_2$, respectively.
:::

However, the converse of this proposition does not hold.

## Interior and Closure

Now we examine the relationship between product sets and interior and closure. First, taking closure behaves well with respect to product sets. That is, the following holds.

::: Proposition 7
Let a product space $X=\prod_{i\in I} X_i$ and, for each $X_i$, arbitrary subsets $A_i$ be given. Then the following formula

$$\prod_{i\in I} \cl A_i=\cl\left(\prod_{i\in I} A_i\right)$$

holds.
:::
::: Proof
First, $\prod_{i\in I}\cl A_i$ is a closed set. This follows from the formula

$$\prod_{i\in I}\cl A_i=\bigcap_{i\in I}\pr_i^{-1}(\cl A_i)$$

and the facts that projections are continuous so each $\pr_i^{-1}(\cl A_i)$ is a closed set, and that an arbitrary intersection of closed sets is closed. Then since $\prod A_i\subseteq \prod\cl A_i$, by the minimality of closure,

$$\cl\left(\prod_{i\in I}A_i\right)\subseteq \prod_{i\in I}\cl A_i$$

holds.

Conversely, suppose $x=(x_i)\in\prod_{i\in I}\cl A_i$ is given, and consider an arbitrary neighborhood of $x$, $V$. Then, considering the base for the product topology, with $x\in\prod U_i\subseteq V$ and, except for finitely many $i$, $U_i=X_i$, there exist open sets $U_i$. For each $i$, since $x_i\in \cl A_i$ and $U_i$ is a neighborhood of $x_i$, by [§Interior, Closure, and Boundary, ⁋Proposition 6](/en/math/topology/other_concepts#prop6){: data-lid="dmcjo" } we have $U_i\cap A_i\neq\emptyset$, and we can choose an element $a_i\in U_i\cap A_i$. Then $a=(a_i)$ is an element of $V\cap \prod A_i$, so every neighborhood of $x$ meets $\prod A_i$, and again by [§Interior, Closure, and Boundary, ⁋Proposition 6](/en/math/topology/other_concepts#prop6){: data-lid="wxoyx" } we have $x\in \cl\left(\prod A_i\right)$.
:::

However, the above proposition does not always hold for interior; it holds only when $I$ is a finite set.

::: Proposition 8
Let a product space with finite index set $I$, $\prod_{i\in I} X_i$, and, for each $X_i$, arbitrary subsets $A_i$ be given. Then the following formula

$$\prod_{i\in I} \interior A_i=\interior\left(\prod_{i\in I} A_i\right)$$

holds.
:::
::: Proof
Since $I$ is a finite set, $\prod_{i\in I}\interior A_i$ is an open set belonging to the base for the product topology discussed above, and is contained in $\prod A_i$. Therefore, by the maximality of interior,

$$\prod_{i\in I}\interior A_i\subseteq \interior\left(\prod_{i\in I}A_i\right)$$

holds.

Conversely, let $x=(x_i)\in\interior\left(\prod A_i\right)$. Then, considering the base, with $x\in \prod U_i\subseteq \prod A_i$, there exist open sets $U_i$. Fixing each $j\in I$, for arbitrary $y_j\in U_j$, the element obtained by replacing in $x$ only the $j$-th component with $y_j$ still belongs to $\prod U_i$ (the other components satisfy $x_i\in U_i$), and therefore belongs to $\prod A_i$. Reading the $j$-th component of this element, we have $y_j\in A_j$. That is, $U_j\subseteq A_j$, and since $U_j$ is an open set, $x_j\in U_j\subseteq \interior A_j$. Since this holds for all $j$, we have $x\in\prod_{i\in I}\interior A_i$.
:::
